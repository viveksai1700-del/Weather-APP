# Weather App

A responsive weather application built with HTML, CSS, and JavaScript that provides live weather information for any city.

## Features

- Search weather by city name
- Live weather information
- Temperature display
- Celsius and Fahrenheit conversion
- Humidity information
- Wind speed
- Feels-like temperature
- Weather condition display
- Dynamic weather backgrounds
- Weather symbols
- Current date and time
- Loading message
- Error handling
- Recent searches
- Local Storage support
- Enter-key search
- Responsive design
- Smooth animations

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Local Storage
