# Weather App

A modern, responsive weather application built with HTML, CSS, and JavaScript that provides real-time weather information for cities around the world.

The application features a clean glassmorphism interface, dynamic weather-based backgrounds, temperature unit conversion, recent search history, and responsive design for desktop and mobile devices.

---

## Overview

The Weather App allows users to search for a city and instantly view its current weather conditions through a simple and intuitive interface.

Weather information is retrieved dynamically through an external weather service and presented in a visually interactive dashboard.

---

## Features

### Weather Information
- Real-time weather data
- Current temperature
- Feels-like temperature
- Humidity
- Wind speed
- Weather condition
- Weather symbols

### User Experience
- City-based weather search
- Celsius and Fahrenheit conversion
- Dynamic weather backgrounds
- Current date and time
- Loading state while fetching data
- User-friendly error handling
- Search using the Enter key
- Recent city searches
- Persistent search history using Local Storage

### Responsive Design
- Fully responsive layout
- Mobile-friendly interface
- Adaptive weather information cards
- Modern glassmorphism UI
- Smooth transitions and animations
